# 计划：参考火山引擎风格的现代化 UI 改版

## 目标

把当前数据管理平台从偏传统后台的样式，升级成更接近火山引擎产品页的现代云产品视觉：

- 更轻、更现代的蓝白科技感
- 顶部区域更有产品感和层次
- 模块卡片更清晰，减少传统表单后台的沉闷感
- 保留数据管理平台的实际操作效率，不做纯营销落地页

## 参考方向

参考页面：

- `https://www.volcengine.com/product/doubao`

可借鉴的结构和视觉语言：

- 顶部 hero 使用浅色科技背景、蓝色主视觉、明确主标题和行动入口
- 内容使用模块化卡片、浅边框、柔和阴影和轻量渐变
- 页面有“产品能力 / 使用场景 / 资源入口 / 定价或说明”式的信息组织
- 视觉更像云服务产品控制台入口，而不是传统管理后台

不会照搬：

- 不做大面积营销文案
- 不做复杂动效
- 不做视频 hero
- 不做无实际功能的产品介绍区

## 设计系统调整

继续使用已安装的 `ui-ux-pro-max`：

- Skill 位置：`.codex/skills/ui-ux-pro-max`
- 当前设计系统：`design-system/lumino-data-platform/MASTER.md`

本次在现有 Data-Dense Dashboard 基础上，叠加更现代的云产品风格：

- 主色保持蓝色系，但从深后台蓝调整到更明亮的云服务蓝
- 增加轻量 gradient surface，但避免装饰性大色块和无意义光斑
- 卡片保持 8px 圆角上限
- 表格和上传区仍然保持高可用、信息密度适中
- 字体继续使用系统字体，避免外部字体网络依赖

## 范围

只修改前端静态资源：

- `internal/app/web/index.html`
- `internal/app/web/styles.css`
- `internal/app/web/app.js`

后端不改。

## 不做什么

- 不引入 React/Vue/构建工具
- 不引入 UI 组件库
- 不引入外部图片、字体或远程资源
- 不改变上传、列表、详情、下载 API
- 不做登录、权限、删除、编辑等新功能

## 实现步骤

1. 页面结构现代化
   - 顶部改成云产品式 hero/workbench header
   - 标题区增加更明确的产品定位
   - 将刷新、系统状态、下载等操作做成更轻的工具入口

2. 核心指标区优化
   - 当前 4 个统计卡片改成更像云服务概览组件
   - 使用浅蓝背景、细边框、轻阴影、强调色数字
   - 保证数据变化不导致布局跳动

3. 上传模块优化
   - 上传区改成更现代的能力卡片
   - 文件选择区域更像云控制台上传入口
   - 保留名称、描述、选中文件、上传状态

4. 数据列表优化
   - 从传统列表按钮改成产品控制台资源列表
   - 增加更清晰的选中态、hover 态、元信息排版
   - 空状态更现代，但不加入冗长说明

5. 详情和预览优化
   - 详情区视觉改成“数据资产详情”
   - 数值统计卡片更轻、更像能力指标
   - 表格保持横向滚动、sticky header、行 hover

6. 响应式和可访问性
   - 375px、768px、1024px、1440px 断点检查
   - hover/focus 状态完整
   - 遵守 `prefers-reduced-motion`
   - 移动端不出现页面级横向滚动

## 风险与待确认

- 火山页面是完整云产品营销页，我们这里是数据管理工作台，需要“参考气质”，不是照搬结构。
- 如果你希望更接近火山首页的营销感，需要增加更多静态说明区；当前计划优先保持工具属性。
- 如果你确认此计划，我再开始改代码。
